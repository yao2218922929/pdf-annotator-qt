# PDF 批注工具（Qt 版）

基于 Python + PySide6 + PyMuPDF 的桌面 PDF 阅读与批注工具，面向阅读技术文档（数据手册、原理图、扫描版教材）的场景。

## 功能

**阅读**

- 多标签页打开多个 PDF，标签可单独关闭，自动记住每个文档的页码与缩放
- 滚轮翻页（连续滚动，滚动到页边缘自动翻到下一页）
- `Ctrl+滚轮` 缩放、适应窗口、页码跳转
- 左侧目录（书签）树、文件夹历史面板
- Markdown 文件阅读（`.md` / `.markdown` / `.txt`）

**批注**

- 矩形、椭圆、直线、箭头、画笔、荧光笔、文字
- 用「选择文字」拖选 PDF 真实文字（自动复制），按 `H` 一键转为高亮批注
- 批注可选、可移动、可删除，支持跨页撤销/重做
- 批注以标准 PDF 注释形式嵌入文件，用其他阅读器打开也能看到
- 颜色可右键自定义，线宽可调
- 左侧批注列表：点击定位、多选批量删除
- 目录（书签）可右键新增、重命名、删除、复制粘贴，也可复制某页为图片

**文字处理**

- 全文搜索（`Ctrl+F`，支持跨文档），命中高亮，选中文字自动填入搜索框
- 划词翻译（`Ctrl+T`），选中文字自动送入翻译面板，源文本可编辑后重新翻译
- 扫描版 PDF 的 OCR 文字层：后台识别并写入不可见文字层，原图不变，之后即可选中、搜索、高亮

**笔记**

- 独立的富文本笔记，可选绑定某个 PDF
- 支持粘贴截图、插入图片（缩放/拖动/右键菜单）
- 可导出为 HTML（图片单独存 `_files` 目录）或 Markdown

## 安装

需要 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
```

依赖说明：

| 包 | 用途 | 是否必需 |
| --- | --- | --- |
| `PySide6` | 界面框架 | 必需 |
| `PyMuPDF` | PDF 渲染与批注写入 | 必需 |
| `markdown` | Markdown 阅读面板 | 必需 |
| `rapidocr` + `onnxruntime` | OCR 文字层 | 可选，不装则 OCR 按钮提示缺依赖 |

## 运行

```bash
python pdf_annotator_qt.py
```

也可以把 PDF 路径作为参数传入，或把 PDF 拖到窗口/程序图标上直接打开：

```bash
python pdf_annotator_qt.py 文档.pdf
```

## 快捷键

所有快捷键都可以在「设置 → 快捷键设置」中修改。

### 文件与视图

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+O` | 打开 PDF |
| `Ctrl+S` | 保存到原文件 |
| `Ctrl+Shift+S` | 另存为批注 PDF |
| `Ctrl+F` | 搜索 |
| `F3` / `Shift+F3` | 下一个 / 上一个搜索命中 |
| `Ctrl+B` | 显示/隐藏文件夹面板 |
| `Ctrl+J` | 笔记面板 |
| `Ctrl+T` | 翻译面板 |
| `←` / `→` | 上一页 / 下一页 |
| `Ctrl+0` | 适应窗口 |
| `Ctrl++` / `Ctrl+-` | 放大 / 缩小 |
| `Esc` | 取消当前操作 / 关闭面板 |

### 工具

| 快捷键 | 功能 |
| --- | --- |
| `Tab` | 循环切换 查看/拖动 → 选择文字 → 选择批注 |
| `1` | 查看/拖动 |
| `2` | 选择文字 |
| `3` | 选择批注 |
| `4` | 荧光笔 |
| `5` | 文字 |
| `6` | 文字高亮 |

### 编辑

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做批注 |
| `Ctrl+C` | 复制选中文字 |
| `H` | 把选中的文字转为高亮批注 |
| `Delete` | 删除选中的批注 |

## 鼠标操作

- **左键拖拽**：使用当前工具绘制或框选
- **中键拖动**：任意工具下平移视图
- **滚轮**：上下翻页；`Ctrl+滚轮` 缩放
- **「画笔」按钮**：左键使用当前画笔工具，右键弹出菜单切换（画笔/荧光笔/矩形/椭圆/直线/箭头）
- **颜色按钮**：左键选用，右键自定义颜色

## 数据存储

配置与用户数据默认保存在用户主目录，不会写入程序目录：

- `~/.pdf_anno_history.json` — 最近打开的文件
- `~/.pdf_anno_progress.json` — 每个文档的阅读进度（页码、缩放）
- `~/.pdf_anno_colors.json` — 自定义颜色
- `~/.pdf_anno_shortcuts.json` — 自定义快捷键
- `~/.pdf_anno_notes.json` — 笔记内容
- `~/.pdf_anno_notes_images/` — 笔记中的图片

笔记的存储目录和图片目录可以在「设置 → 笔记设置」中修改。

## 目录结构

```
pdf_annotator_qt.py     入口：MainWindow 组装与启动
pdfanno/                功能模块（mixin 拆分）
  ui_mixin.py           工具栏、颜色、快捷键
  session_mixin.py      多标签会话、打开/切换文档
  render_mixin.py       页面渲染、翻页、缩放
  anno_mixin.py         批注绘制、命中与删除
  annolist_mixin.py     批注列表
  search_mixin.py       搜索面板
  ocr.py                OCR 文字层（后台线程）
  note_panel.py         笔记面板与富文本编辑器
  markdown_panel.py     Markdown 阅读
  translate.py          翻译
  hier_mixin.py         原理图层级链接导航
  pdfcore.py            PDF 读写与批注序列化
  config.py             配置文件读写
build.py                打包为单文件 .pyw
requirements.txt        依赖清单
```

## 打包

生成单文件部署版本（内嵌源码，可放在桌面双击运行，目标机器仍需安装依赖）：

```bash
python build.py
```

## 说明

- OCR 使用 RapidOCR + ONNX Runtime，模型随包提供，可离线运行；约每页数秒，识别在后台进行，期间可以继续阅读。
- 批注嵌入 PDF 文件本身，不依赖本工具也能显示；但只有本工具能编辑已嵌入的批注。
